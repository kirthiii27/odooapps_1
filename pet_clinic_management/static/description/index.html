🐾 Pet Clinic / Veterinary Management

Manage pets, appointments, vaccinations, treatments, and prescriptions in your clinic efficiently. Designed for veterinary professionals using Odoo.

🧩 Key Features

  • Register and manage pets with breed, age, and owner details
  • Book and manage appointments with doctors
  • Record vaccinations with configurable vaccine names
  • Manage pet treatments and case notes
  • Create prescriptions using medicine master data
  • Full date-based pet code generator (e.g., PET0826IM07)
  • Configurable vaccine and medicine master under settings
